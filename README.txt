DASHBOARD PORTAL TEMPLATE
==========================
วิธีใช้งาน:
1. เปิดไฟล์ data.js ด้วย Notepad หรือ VS Code
2. เปลี่ยน department, title, category, description และ url
3. บันทึกไฟล์
4. เปิด index.html ด้วย Chrome/Edge
5. เมื่อคลิก "เข้าสู่ Dashboard" ระบบจะเปิดลิงก์ในแท็บใหม่

หมายเหตุ:
- ต้องเก็บ index.html และ data.js ไว้ในโฟลเดอร์เดียวกัน
- ลิงก์สามารถเป็น Google Looker Studio, Power BI, Tableau, Google Sheets หรือเว็บ Dashboard อื่นได้
- หากต้องการเผยแพร่บนอินเทอร์เน็ต สามารถนำโฟลเดอร์นี้ขึ้น GitHub Pages, Google Drive/เว็บเซิร์ฟเวอร์ หรือโฮสติ้งของหน่วยงานได้
